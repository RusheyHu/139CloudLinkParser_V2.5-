# 中国移动云盘直链助手 V2.5（仅我的云盘版）

## 本版修改

- 已彻底移除“分享文件”页面、标签页及其所有界面控件。
- 已移除分享链接解析、分享目录读取、分享文件夹导航和分享直链申请代码。
- 保留“我的云盘”功能：扫码登录、个人云盘目录读取、文件夹导航、搜索、排序、文件夹大小统计和文件直链解析复制。
- 不自动下载文件，只把下载 URL 写入 Windows 剪贴板。
- 登录 Cookie 保存在当前 Windows 用户目录 `~/.139_link_parser/cookies.json`，请勿分享该文件。

## 我的云盘功能

- 支持根目录、进入文件夹、返回上级、刷新和面包屑路径导航。
- 支持当前目录搜索及全云盘递归搜索；支持名称关键词、扩展名、英文大小写不敏感匹配。
- 点击“文件名称 / 类型 / 大小 / 修改时间”表头排序，再次点击切换升序/降序。
- 文件夹始终置顶；点击“大小”表头时，可在后台递归统计文件夹内所有普通文件的总大小，并缓存统计结果。
- 普通文件右侧点击“解析并复制”，通过个人云盘下载接口获取直链并复制到剪贴板。

## Windows 本地打包

1. Windows 10/11 安装 Python 3.11。
2. 安装 Microsoft Edge 或 Google Chrome。
3. 解压项目，在项目目录双击 `build_windows.bat`。
4. 输出位于 `dist\139CloudLinkParserV2_5\139CloudLinkParserV2_5.exe`。
5. 发布时保留整个 `dist\139CloudLinkParserV2_5` 文件夹。

## GitHub Actions 打包

将项目全部文件（包括 `.github` 目录）上传到 GitHub 仓库。进入 Actions，运行 `Build Windows EXE`，完成后下载 Artifacts 中的 Windows x64 构建产物。

## 使用

1. 启动程序，点击右上角“扫码登录”，使用移动云盘 App 扫码登录。
2. 在“我的云盘”页面点击“刷新列表”。
3. 双击文件夹或点击“打开文件夹”进入目录；通过面包屑路径或“返回上级”返回。
4. 使用搜索框查找当前目录或全云盘文件。
5. 点击表头排序；点击文件行右侧“解析并复制”获取下载直链。

## 安全与说明

- 不要把 `cookies.json`、完整下载直链或带签名参数的 URL 发给他人。
- 直链可能有时效；获取后及时使用。
- 个人云盘接口需要使用真实账号登录态验证；如果接口返回鉴权错误，请重新扫码登录。
